# GR52 Bivouac Dossier

A seven-day tent crossing of the GR52 from Saint-Dalmas-Valdeblore to Menton, 12 to 18
September 2026. Day plan, maps, park rules, water, refuges, technical options and transport, in
English and Hebrew.

Live at [gr52.yarden-zamir.com](https://gr52.yarden-zamir.com). The GPX for OsmAnd is at
[/GR52_all-in-one.gpx](https://gr52.yarden-zamir.com/GR52_all-in-one.gpx).

## Layout

- `site/`: the static page and the GPX file.
- `container/Caddyfile`: the file server inside the container.
- Deployment: see `kitshn.md`.

## Update

Edit `site/index.html`, push to `main`. A pull request gets a preview at
`pr.<number>.gr52.yarden-zamir.com`.
